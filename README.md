# Warrq — Arabic Reading Tracker

A frontend learning project using HTML, CSS and JavaScript.

## Files
- `index.html`, `script.js`, `style.css` — main page and assets.
- `books.html`, `books.js` — books page and its scripts.

## Run locally
Download the repository and open `index.html` in a modern browser. Explore the books page from the interface.

## Status
The repository contains a frontend app. Backend services and authentication are not claimed. Persistence behavior, mobile layout and input handling require functional verification before documenting them as supported features.
